# 30 Days of Go - From Zero to Broker

Learning Go by building one project a day. No tutorials, only docs.

### Roadmap - Week 1

**Day 1: Expense Splitter** - `fmt.Scan`, variables, if/else  
**Day 2: Password Checker** - `for`, functions, multiple returns  
**Day 3: Log Analyzer** - `os.ReadFile`, `map`, counting  
**Day 4: Contact Book** - `struct`, `json`, `os.Args`  
**Day 5: Bank Account** - Methods, pointer receiver, encapsulation  
**Day 6: Shape Calculator** - Interfaces  
**Day 7: URL Status Checker** - `net/http`, mini project
